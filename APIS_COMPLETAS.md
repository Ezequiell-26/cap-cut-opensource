## 🔧 Configuración de APIs

### Sin API Key Requerida (Listas para usar)
```cpp
// Mixkit, Coverr, Mazwai, Life of Vids
auto* stockApi = new PremiumStockApi(this);
stockApi->searchVideos("nature", 1, [](const QVector<StockVideo>& videos) {
    // Usar videos
});

// Google Fonts, Phosphor Icons
auto* assetsApi = new AssetsApi(this);
assetsApi->loadFont("Roboto", "400");

// Reddit (solo requiere User-Agent)
auto* socialApi = new SocialMediaApi(this);
socialApi->setRedditUserAgent("CCOS-Editor/1.0");
socialApi->getHotPosts("technology", 25, callback);

// Ollama, LM Studio, LocalAI (locales)
auto* aiApi = new AdvancedAI(this);
aiApi->setOllamaProvider("http://localhost:11434");
```

### Con API Key Gratuita
```cpp
// YouTube
auto* socialApi = new SocialMediaApi(this);
socialApi->setYouTubeApiKey("TU_API_KEY");

// Giphy
socialApi->setGiphyApiKey("TU_API_KEY");

// Pixabay
auto* stockApi = new PremiumStockApi(this);
stockApi->searchPixabayVideos("nature", "TU_API_KEY", 1, callback);

// Google Cloud (TTS/STT)
auto* accessApi = new AccessibilityApi(this);
accessApi->setGoogleCloudApiKey("TU_API_KEY");
```
