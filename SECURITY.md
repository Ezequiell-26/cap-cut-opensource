# Security Policy

## Supported versions

The `main` branch is the active development line.

## Reporting vulnerabilities

Do not publish exploitable details in a public issue. Report security problems privately through the repository's configured GitHub security contact or maintainer channel.

Include:

- affected version/commit
- platform
- reproduction steps
- expected behavior
- actual behavior
- impact assessment if known

Do not include secrets, personal data, or private media files in reports.
